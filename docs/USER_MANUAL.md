## 1. Description du Système
La plateforme **GRAVITY OSINT** est un outil tactique de cyber-renseignement (Cyber Intelligence) conçu pour les agences gouvernementales, la lutte anti-terroriste et la criminalistique financière. Elle agrège, analyse et visualise des milliards de points de données pour révéler l'invisible.

## 2. Capacités Offensives (Modules)

### A. Graph Intelligence Engine (Core)
*   **Fonction**: Visualisation relationnelle dynamique.
*   **Action**: Tracez les connexions cachées entre Personnes, Emails, Serveurs et Crypto-Actifs.
*   **Technique**: Algorithme de détection de communautés (Community Detection).

### B. High Value Target (HVT) Identifier
*   **Fonction**: Calcul mathématique du "Chef de Réseau".
*   **Action**: Analysez la centralité (Degree Centrality) pour isoler la cible prioritaire.
*   **Usage**: Onglet "AI Analysis" > "Risk Score".

### C. Surveillance Globale (Live Feed)
*   **Fonction**: Interception simulée de flux de données (TOR, Pastebin, DarkWeb).
*   **Action**: Console "GRAVITY_INTERCEPT_V4" en bas de l'écran.
*   **Contenu**: Alertes de scan de ports, transactions suspectes, fuites de bases de données.

### D. Opérations Spéciales (Black Ops)
1.  **Biometric Facial Scan**:
    *   Cible: Nœuds "Personne".
    *   Tech: Analyse réseau neuronal (128 points faciaux) + Cross-reference Interpol.
2.  **PGP Decryption**:
    *   Cible: Nœuds "Serveur" / "Crypto".
    *   Tech: Attaque par dictionnaire (Rainbow Table) + Brute-force RSA-4096.

### E. Breach Intelligence (Fuites de Données)
*   **Fonction**: Révéler les identifiants compromis.
*   **Action**: Clic-droit sur Email > "Check Leaks".
*   **Résultat**: Mot de passe masqué (ex: `P*****493`) + Source (Adobe, LinkedIn).

## 3. Guide de l'Opérateur (Mission Démo)

### SCÉNARIO TACTIQUE: "OPÉRATION CHIMERA"
Pour démontrer la puissance de l'outil à un client VIP :

1.  **Infiltration**: Lancez `LAUNCH_PLATFORM.bat`. Connectez-vous (ID: `admin`, 2FA: `111111`).
2.  **Traque**: Cherchez le nom de code **"CHIMERA"** dans la barre de recherche.
3.  **Expansion**:
    *   Cliquez sur le nœud **"X (The Architect)"**.
    *   Cliquez sur ses lieutenants ("Viper", "Ghost").
4.  **Action**:
    *   Lancez un **Scan Biométrique** sur "X".
    *   Détectez la **Fuite de mot de passe** sur l'email de "Viper".
    *   Déchiffrez le trafic du Serveur "Command & Control".
5.  **Conclusion**:
    *   Allez dans l'onglet **"AI Analysis"** pour voir le score de risque (Risk Score).
    *   Cliquez sur **"Reports"** pour générer le Dossier PDF de preuves.
